# Precision Sequence Website

A modern, research-focused peptide e-commerce style website for precisionsequence.com.

## Features
- Age gate (21+) with research use disclaimer
- Homepage with hero, trust signals, and featured products
- Full product catalog (shop.html) with popular research peptides
- Quality & CoA page
- About and Contact pages
- Functional cart (localStorage demo)
- Responsive design using Tailwind CSS
- Strong legal disclaimers throughout

## Deployment
This is a static HTML/CSS/JS site. Deploy to any static host:
- Vercel (recommended, drag-and-drop or Git)
- Netlify
- GitHub Pages
- Any web server

## Important Legal Notes
All products are for **laboratory research use only**. Not for human or animal consumption. Not FDA approved. The site includes appropriate disclaimers. You are responsible for ensuring compliance with all applicable laws regarding the sale of research chemicals/peptides in your jurisdiction.

## Customization
- Edit product data in `script.js` (PRODUCTS array)
- Update colors in Tailwind config within each HTML file
- Replace logo.jpg with your own branding
- Connect a real payment processor (Stripe, etc.) and backend for live orders
- Add real CoA PDFs and product images
